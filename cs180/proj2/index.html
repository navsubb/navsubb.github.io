Fun with Filters and Frequencies

For this project, I implement convolution and use image filters to find edges, sharpen images, and combine information at different frequencies.

Part 1.1: Convolutions from Scratch

I wrote two convolution functions using only NumPy. Each flips the filter horizontally and vertically, then slides it across the image. At each position, it multiplies the image neighborhood by the flipped filter and sums the products to get one output pixel. The four-loop version loops over rows, columns, and both filter dimensions. The two-loop version keeps the row and column loops but uses NumPy to multiply and sum the whole neighborhood.

Both functions use zero-filled same padding, which keeps the output the same size as the input. The 9×9 box filter needs four pixels of padding on every side. The 1×2 x filter needs one column on the left, and the 2×1 y filter needs one row at the top. This placement matches SciPy’s convention for even-sized filters. All pixels outside the image are treated as zero.

Four-loop implementation

def convolve_four_loops(photo, filt):
    filt_rows, filt_cols = filt.shape
    pad_rows = (filt_rows // 2, (filt_rows - 1) // 2)
    pad_cols = (filt_cols // 2, (filt_cols - 1) // 2)

    bordered = np.pad(photo, (pad_rows, pad_cols))
    flipped = filt[::-1, ::-1]
    result = np.zeros_like(photo, dtype=float)

    for row in range(photo.shape[0]):
        for col in range(photo.shape[1]):
            for filt_row in range(filt_rows):
                for filt_col in range(filt_cols):
                    result[row, col] += (
                        bordered[row + filt_row, col + filt_col]
                        * flipped[filt_row, filt_col]
                    )

    return result

Two-loop implementation

def convolve_two_loops(photo, filt):
    filt_rows, filt_cols = filt.shape
    pad_rows = (filt_rows // 2, (filt_rows - 1) // 2)
    pad_cols = (filt_cols // 2, (filt_cols - 1) // 2)

    bordered = np.pad(photo, (pad_rows, pad_cols))
    flipped = filt[::-1, ::-1]
    result = np.zeros_like(photo, dtype=float)

    for row in range(photo.shape[0]):
        for col in range(photo.shape[1]):
            patch = bordered[
                row : row + filt_rows,
                col : col + filt_cols,
            ]
            result[row, col] = np.sum(patch * flipped)

    return result

Part 1.2: Finite Difference Operator

I convolve the cameraman image with Dx = [1, −1] and Dy = [1, −1]T. I combine the two partial derivatives to compute the gradient magnitude:

‖∇I‖ = √[(Dx * I)² + (Dy * I)²]

With input intensities in [0, 1], I mark pixels white when the gradient magnitude exceeds 0.15 and black otherwise. A threshold of 0.10 keeps more distracting grass texture; 0.20 removes more of it but breaks up weaker edges around the head and camera. I chose 0.15 to keep more of those outlines, accepting some remaining grass texture.

Gray represents zero in the derivative images. The bright outer border in the magnitude and edge images comes from zero padding.

Part 1.3: Derivative of Gaussian

In Part 1.2, the difference filters picked up many small changes in the grass as well as the edges of the cameraman. To reduce these distracting responses, I first smooth the image with a Gaussian. I use cv2.getGaussianKernel(9, 2) to create a 1D kernel, then multiply it by its transpose to form a 9×9 filter with σ = 2. Its weights sum to 1 and give more weight to pixels near the center.

After blurring, I apply the same x and y difference filters and combine their responses into the gradient magnitude. I threshold at 0.04, lower than Part 1.2’s 0.15 because smoothing spreads intensity changes over more pixels and reduces their peak strength. Most of the grass texture disappears while the cameraman and tripod outlines remain. The edges are wider, and some fine details in the face and background are lost.

Combining the filters

Blurring and then differentiating can also be done with one combined filter per direction. I convolve the Gaussian with Dx and Dy to make two derivative-of-Gaussian (DoG) filters. This works because convolution is associative: the filters can be combined before applying them to the image.

(I * G) * D = I * (G * D) 
gauss_line = cv2.getGaussianKernel(9, 2)
gauss = gauss_line @ gauss_line.T
dog_x = convolve2d(gauss, dx, mode="full")
dog_y = convolve2d(gauss, dy, mode="full")

I use mode="full" to keep the complete filters. Their positive and negative weights measure changes between neighboring regions while incorporating Gaussian smoothing. I apply each DoG filter directly to the original image, then compute the gradient magnitude and use the same 0.04 threshold.

Both Part 1.3 magnitude images use the same brightness scale. Gray represents zero in the DoG filters.

The two approaches produce the same interior gradient magnitude up to floating-point rounding. After excluding a 9-pixel border, np.allclose passes, with a maximum difference of about 8 × 10−16. The borders can differ because the blur-then-differentiate method crops the intermediate image and pads it with zeros again. The bright outer edges are caused by that zero padding, not by objects in the scene.

Part 2.1: Image Sharpening

A Gaussian blur smooths away high-frequency detail while retaining low-frequency structure. Subtracting the blurred image from the original gives a high-frequency residual containing edges, fine detail, and noise. I sharpen the image by adding a scaled version of this residual back to the original.

Isharp = I + α(I − G * I)

I combine these operations into one filter, (1 + α)δ − αG, where δ is 1 at the center and 0 elsewhere. I apply it once per color channel and clip the result to [0, 1]. At α = 0, the image is unchanged; larger values strengthen detail but can also exaggerate noise and outlines.

At α = 0.5, the change is subtle. At α = 1, the building’s edges and surface patterns become clearer. At α = 2, those details are strongest, but dark outlines and contrast are also more pronounced.

Blurring and recovering a sharp image

Once the blur removes those high frequencies, unsharp masking can strengthen the remaining edges but cannot reconstruct the lost information.

Part 2.2: Hybrid Images

A hybrid image changes with viewing distance: fine detail stands out up close, while broad shapes become easier to see from farther away. I blur one image to keep its low frequencies and subtract a blurred copy from the other to get its high frequencies. Before filtering, I align each pair using two corresponding landmarks.

For the two custom hybrids, I use σ = 14 for the low-pass component and σ = 5 for the high-pass component, then add them:

H = G14 * Ilow + (Ihigh − G5 * Ihigh)

I clip this sum to [0, 1] for the final image. The Derek/Nutmeg sample below uses different blur widths and averages the components instead.

Starter example: Derek and Nutmeg

Nutmeg’s whiskers and fur provide the close-up detail, while Derek’s face provides the broad shape. I use the starter alignment functions to match their eyes, rotating Nutmeg while keeping Derek upright. I use σ = 8 for Nutmeg’s high-pass component and σ = 12 for Derek’s low-pass component, then average them:

Hsample = clip([G12 * IDerek + (INutmeg − G8 * INutmeg)] / 2, 0, 1)

Averaging makes the result darker without changing the components’ relative weights before clipping. Nutmeg is clearer up close; shrinking the image or stepping back makes Derek easier to see.

Koala and grizzly bear

The koala’s rounded head and large ears remain recognizable after blurring, while the grizzly’s fur and facial edges provide strong close-up detail. I align their eyes by scaling, rotating, and shifting the grizzly to match the koala, then crop both to the same viewing area.

I tried high/low σ pairs of (3, 8), (5, 14), and (8, 20). At (3, 8), the koala remains prominent up close; at (8, 20), the bear dominates more strongly. Here σ is the Gaussian width in pixels: larger values produce stronger blur, and subtracting that blur retains a broader range of detail in the high-pass component.

Part 2.3: Gaussian and Laplacian Stacks

I build six Gaussian levels, starting with the original image. Each new level blurs the previous one with σ = 2, 4, 8, 16, or 32. I keep every level at 300 × 300 pixels, without downsampling, and reflect the image at its boundaries. RGB channels are filtered separately.

The Laplacian levels are the differences between neighboring Gaussian levels: Li = Gi − Gi+1. The last level keeps G5, the remaining low frequencies. Adding all six levels reconstructs the original image; the maximum error for these inputs is about 1.1 × 10−16.

Part 2.4: Multiresolution Blending

I reuse the six-level stacks from Part 2.3. For each pair, I build Laplacian stacks for both images and a Gaussian stack for a binary mask. White selects the source and black selects the background. At each level, I combine the bands using the blurred mask, then sum all six levels and clip the result to [0, 1].

Bi = MiLsource,i + (1 − Mi)Lbackground,i
Result = ∑ Bi

The mask transition widens at coarser levels, blending broad color changes while keeping fine detail. For both pairs, I compare a vertical split with a simple oval mask. I use the same relative oval size and blur settings, shifting the oval farther right to surround me in the Mount Rainier photo.

What I learned

My biggest takeaway was seeing how the same idea—separating and recombining spatial frequencies—shows up across very different image-processing techniques. Sharpening, hybrid images, and multiresolution blending made frequency-based reasoning about images feel much more concrete.
